# Contributing

Contributions are welcome when they improve evidence, reproducibility, or review quality.

Before proposing a new case, read the methodology and evidence standard. Add the source to the frozen manifest, create a case from the template, update the case index, and run validation. One pull request should normally contain one case or one clearly related correction.

Do not submit hypothetical examples, copied accusations, unstable search links, or claims about a source author's intent. If evidence is incomplete, use `ambiguous` and state what is missing.

By contributing, you agree that original annotations and code you submit may be distributed under this repository's data and code licenses. Do not upload third-party datasets or full notebooks unless their licenses clearly permit it.
